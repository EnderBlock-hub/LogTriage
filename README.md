# LogTriage — учебный проект по автоматизации анализа логов

Небольшой Python-проект на 3–4 дня: чтение событий входа Windows, поиск подозрительных последовательностей и генерация отчётов.

## День 1

Открой `DAY1.md`. В `data/` находятся одинаковые синтетические события в двух форматах — CSV и JSON.

Ожидаемые команды после самостоятельной реализации парсера:

```bash
python main.py data/events.csv
python main.py data/events.json
```

**Важно:** `main.py` не включён специально, чтобы ты написал его сам. IP-адреса относятся к частной лабораторной сети, никаких реальных персональных данных нет.
