# LogTriage — день 1: чтение и нормализация событий

**Ориентир:** 2–4 часа. **Цель:** самостоятельно написать простой CLI-парсер CSV/JSON, который выводит события входа в Windows и сводную статистику. Пока без обнаружения атак, отчётов HTML и сложных зависимостей.

## Исходные данные

- `data/events.csv` — набор синтетических Windows Security-событий в CSV.
- `data/events.json` — **те же события** в JSON-массиве. Не складывай показатели двух файлов вместе: это два варианта одного датасета.
- Все события придуманы для учебного задания, реальные IP-адреса/учётные данные не использованы.
- Время указано в **UTC** в формате ISO 8601: `2026-11-07T09:00:00Z`.
- Схема каждого события: `timestamp`, `event_id`, `username`, `source_ip`, `computer`, `logon_type`.
- `event_id`: `4624` — успешный вход; `4625` — неудачный вход. Другие ID сейчас пропускаем.
- `source_ip = "-"` означает, что IP не указан (например, локальный вход). Это **не ошибка файла**.
- В CSV идентификаторы событий будут строками; в JSON — числа.

## Задание

1. Создай Git-репозиторий и файл `main.py`. Используй стандартную библиотеку Python (без pandas).
2. Сделай функцию `load_events(path)`, которая открывает `.csv` через `csv.DictReader`, а `.json` — через `json.load`, и возвращает **список словарей**. Если расширение другое или файл отсутствует, покажи понятную ошибку.
3. Сделай функцию `normalize_event(row)`: приведи `event_id` к `int`, `timestamp` к `datetime` с часовым поясом, вытащи `username`, `source_ip`, `computer`, `logon_type`. Для `source_ip = "-"` можешь сохранить `None` или отображать `N/A`.
4. Оставь для анализа только события `4624` и `4625`. Обозначь их как `SUCCESS` и `FAIL`.
5. Выведи в консоль события в формате `2026-11-07 09:00:00+00:00 | FAIL | Administrator | 192.168.244.20 | DC1` (время здесь только пример формата).
6. В конце выведи: число **всех записей**, число событий входа, количество `SUCCESS`, количество `FAIL`. Данные из CSV и JSON должны давать **одинаковую сводку**.

## Пример запуска

```powershell
python main.py data/events.csv
python main.py data/events.json
```

## Контрольные результаты

Сверь их со своим выводом, когда напишешь код:

- Всего записей: **38**.
- Событий входа (`4624` + `4625`): **35**.
- Успешных (`4624`): **12**.
- Неуспешных (`4625`): **23**.
- Прочих событий: **3** (игнорируются в списке входов, но учитываются в общем числе).
- У событий с неизвестным IP (`-`): **3** записи, включая одно событие, которое не является входом.

## Проверка готовности

- [ ] Обрабатываются оба формата.
- [ ] `4624/4625` распознаются независимо от того, строки это или числа.
- [ ] Времена нормально парсятся с `Z` (UTC).
- [ ] Пропущенный IP не вызывает аварийного завершения.
- [ ] Другие Event ID не попадают в список входов.
- [ ] Итоговые числа совпадают с контрольными.
- [ ] Функции разделены, а не весь код внутри одного большого цикла.
